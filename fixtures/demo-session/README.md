## Things worth testing in Map
- Corrections are applied in `seq` order. A correction can target an utterance, an answer, an action or a Work Map ref, and it can arrive minutes later in a different phase.
- Every step and guardrail has ≥1 `moment` (frame) and every guardrail has ≥1 `quote` with word-accurate `t`/`tEnd`. Use `utterance.payload.words`.

- Off-record span: there must be no frame, event or quote inside `[2:17.4, 2:44.4)`.
- `screen.action.evidence` links ground-truth `app.event`s and vision `screen.observed` events. Vision is noisier, with partial text while typing.
